# Análisis de Estilos UI - GoBond!

He analizado el proyecto para identificar dónde se definen y aplican los estilos visuales (colores, fuentes, etc.).

## Ubicación de los Estilos Centrales

La mayoría de la configuración visual del proyecto se encuentra centralizada en el archivo [index.html](file:///c:/Users/Juan%20Ga/Desktop/Coder/IA/GoBond!/index.html).

### 1. Configuración de Tailwind CSS
Dentro de la etiqueta `<script>` en `index.html` (líneas 13-36), se encuentra la extensión del tema de Tailwind:
- **Colores personalizados**:
  - `primary`: `#2f7f33` (Verde principal)
  - `background-light`: `#f6f8f6`
  - `background-dark`: `#141e15`
  - `surface-variant`: `#e1e5df`
  - `alert-yellow`: `#fef9c3`
  - `alert-border`: `#fde047`
- **Fuentes**: `Inter` (definida como la familia principal).
- **Bordes**: Radios de borde personalizados `lg` (1rem) y `xl` (1.5rem).

### 2. Estilos Globales (CSS)
En la etiqueta `<style>` de `index.html` (líneas 37-86) se definen:
- Ajustes para los iconos de **Material Symbols**.
- La fuente base del `body`.
- Animaciones personalizadas: `fade-in` y `slide-up`.
- Utilidades para ocultar barras de desplazamiento (`no-scrollbar`).

### 3. Fuentes e Iconos
Se importan directamente desde Google Fonts en el `<head>` de `index.html`:
- **Fuente**: [Inter](https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900&display=swap)
- **Iconos**: [Material Symbols Outlined](https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined:wght,FILL@100..700,0..1&display=swap)

## Aplicación de Estilos en Componentes

Los estilos se aplican directamente en los archivos de React utilizando clases de Tailwind CSS.

- **[App.tsx](file:///c:/Users/Juan%20Ga/Desktop/Coder/IA/GoBond!/App.tsx)**: Contiene la lógica del modo oscuro y aplica la mayoría de las clases visuales de la interfaz principal (modales, buscador, avisos).
- **[Layout.tsx](file:///c:/Users/Juan%20Ga/Desktop/Coder/IA/GoBond!/components/Layout.tsx)**: Define la estructura visual de la barra lateral (sidebar) y la navegación móvil, usando `bg-background-dark` y `bg-white` de forma dinámica.

## Modo Oscuro
El sistema de modo oscuro funciona mediante la clase `.dark` en el elemento `<html>`. Tailwind utiliza esta clase para alternar entre los colores de fondo y texto definidos en la configuración.
